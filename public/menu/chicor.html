신세계의 뷰티 드럭스토어 ‘Chicor’ 앱 구축 프로젝트에 참여했습니다. 사용자의 피부 상태와 취향 데이터를 기반으로 개인화된 제품 추천 경험을 설계하여, 수많은 제품 속에서 쉽게 선택할 수 있는 환경을 만드는 데 집중했습니다.

 

온라인과 오프라인을 연결하는 멤버십 경험을 통합하고, 사용자가 혜택과 정보를 직관적으로 이해할 수 있도록 UI 구조와 데이터 표현 방식을 설계했습니다.

Project Goal

사용자 데이터를 기반으로 개인화된 뷰티 경험을 제공하고, 온·오프라인을 연결하는 통합 쇼핑 경험을 설계하는 것을 목표로 했습니다.

Solution 01 (Personalization)

피부 타입, 피부톤, 연령 등의 데이터를 수집하는 '피부 진단' 프로세스를 설계했습니다.
분석 결과를 기반으로 사용자에게 맞는 제품을 추천하여 탐색 효율을 높이고 개인화 경험을 강화했습니다.

Solution 02 (Membership UX)

온라인 쇼핑과 오프라인 매장 혜택을 하나의 흐름으로 연결하는 멤버십 UI를 설계했습니다.
포인트, 쿠폰, 등급 정보를 시각화하여 사용자가 혜택을 쉽게 이해하고 활용할 수 있도록 구성했습니다.

The Result

'피부 진단' 기능 참여율 60% 달성, 개인화 추천 기반으로 구매 전환율이 약 10% 증가했습니다.
데이터 기반 큐레이션을 통해 사용자의 선택 과정을 효율적으로 개선했습니다.

My Strength

이커머스 도메인에서 데이터를 사용자 경험으로 연결하는 설계를 진행했습니다.
복잡한 정보를 직관적으로 시각화하여 사용자가 쉽게 이해하고 선택할 수 있는 UX를 구현했습니다.
