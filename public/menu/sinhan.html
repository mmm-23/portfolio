info

은행·카드·증권·보험으로 분산된 금융 서비스를 하나의 브랜드 경험으로 통합했습니다. 복잡한 데이터를 직관적으로 시각화하고, 일관된 정보 구조와 디자인 원칙(SOLID System)을 적용하여 사용자가 신뢰할 수 있는 안정적인 금융 플랫폼을 구축했습니다.

 

단순한 기능 통합을 넘어, 앱 간의 경계를 허물어 사용자의 불편을 해소하는 데 집중했습니다. 단일 앱 내에서 모든 금융 업무가 유기적으로 연결되는 'Super SOL'만의 심리스(Seamless)한 흐름을 디자인과 설계를 통해 완성했습니다.

Project Goal

은행·카드·증권·보험 등 각각 분리되어 있던 금융 서비스를 하나의 브랜드 경험으로 통합하고, 복잡한 데이터 구조를 직관적으로 이해할 수 있는 안정적인 시각 원칙 구축.

Solution 01 (Design System)

SOLID 디자인 시스템을 기반으로 UI 규칙을 통합하고 반복 요소를 컴포넌트화하여 서비스 간 이동 시 시각적·기능적 흐름을 자연스럽게 연결(시스템 적용률 86%).

Solution 02 (UX Structure)

방대한 금융 데이터를 '핵심-보조-확장' 구조로 재구성하고 캐러셀 UI를 도입하여 탐색 흐름 단순화 및 단계적 정보 노출.

The Result

주요 과업(계좌조회, 카드 내역 확인 등)의 평균 이동 동선 37% 단축, 슈퍼앱 확장을 위한 안정적 기반 마련.

My Strength

대규모 시스템의 컴포넌트 설계 및 Figma 프로토타이핑 주도.
