신한은행, 카드, 증권, 보험 등 분산되어 있던 금융 서비스를 하나의 앱으로 통합하는 프로젝트에 참여했습니다. 서로 다른 데이터 구조와 UI 규칙을 일관된 정보 구조와 시각적 시스템으로 정리하여, 사용자가 하나의 서비스처럼 자연스럽게 이용할 수 있도록 설계했습니다.

 

복잡한 금융 데이터를 직관적으로 이해할 수 있도록 정보 계층과 탐색 흐름을 재구성하고, 사용자가 필요한 정보에 빠르게 도달할 수 있는 경험을 만드는 데 집중했습니다.

Project Goal

분산된 금융 서비스를 하나의 흐름으로 통합하고, 복잡한 데이터 구조를 사용자가 쉽게 이해할 수 있는 일관된 사용자 경험으로 재설계하는 것을 목표로 했습니다.

Solution 01 (Design System)

SOLID 디자인 시스템을 기반으로 각 서비스별로 분리되어 있던 UI 구조를 하나의 기준으로 정리했습니다.
조회, 입력, 피드백 패턴을 통합하고 반복되는 요소를 컴포넌트화하여 서비스 간 이동에서도 일관된 경험을 유지할 수 있도록 설계했습니다.

Solution 02 (UX Structure)

금융 데이터의 복잡도를 낮추기 위해 '핵심 - 보조 - 확장' 구조로 정보 계층을 재설계했습니다.
중요한 정보는 상단에 배치하고, 세부 정보는 필요 시 확장되는 방식으로 구성하여 사용자가 흐름을 끊지 않고 탐색할 수 있도록 설계했습니다.

The Result

주요 기능 이용 시 사용자 이동 동선이 약 37% 단축되었으며, 불필요한 클릭 수 감소를 통해 정보 탐색 효율이 개선되었습니다.
복잡하게 분산되어 있던 금융 기능을 하나의 일관된 경험으로 통합하는 기반을 구축했습니다.

My Strength

Figma 기반 프로토타이핑과 UI 구조 설계를 주도하며, 복잡한 금융 데이터를 사용자 관점에서 재구성했습니다.
디자인 시스템과 정보 구조 설계를 통해 서비스 전반의 일관성과 확장성을 고려한 경험을 설계했습니다.
