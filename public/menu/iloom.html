일룸 브랜드를 기반으로 제품 경험을 시각적으로 전달하는 웹 페이지를 디자인하고 구현한 프로젝트입니다. 가구의 구조와 사용 맥락을 사용자가 직관적으로 이해할 수 있도록 레이아웃과 인터랙션을 설계했습니다.

 

디자인부터 프론트엔드 구현까지 직접 진행하며, 스크롤 기반 인터랙션과 모션을 통해 콘텐츠 몰입도를 높이는 데 집중했습니다.

Project Goal

제품 정보를 나열하는 것이 아니라, 사용자가 공간과 제품을 함께 상상할 수 있는 경험 중심의 웹 페이지를 만드는 것을 목표로 했습니다.

Solution 01 (Layout & Visual)

가구의 구조와 배치를 고려하여 콘텐츠를 단계적으로 노출하는 레이아웃을 설계했습니다.
이미지 중심의 구성과 여백을 활용해 제품이 돋보이도록 시각적 흐름을 만들었습니다.

Solution 02 (Interaction)

스크롤에 반응하는 인터랙션과 모션을 적용하여 사용자가 자연스럽게 콘텐츠를 탐색하도록 설계했습니다.
단순한 정적 페이지가 아닌, 사용 경험을 유도하는 흐름 중심의 웹을 구현했습니다.

The Result

디자인과 구현을 동시에 고려한 구조로 의도한 사용자 경험을 실제 결과물로 구현했습니다.
인터랙션을 통해 콘텐츠 몰입도를 높이고, 제품 이해도를 자연스럽게 유도하는 웹 경험을 완성했습니다.

My Strength

디자인뿐만 아니라 HTML, CSS, JavaScript 기반으로 직접 구현하여 디자인 의도를 그대로 결과물에 반영할 수 있습니다.
디자인과 개발 사이의 간극을 줄이는 실행 중심의 작업 방식을 가지고 있습니다.
