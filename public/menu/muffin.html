MOBILE APP, UX DESIGN, SERVICE DESIGN

info

오프라인 중심의 주유, 세차, 멤버십 경험을 하나의 모바일 서비스로 통합하는 프로젝트에 참여했습니다. 복잡하게 분산된 차량 관리 서비스를 사용자가 쉽게 이해하고 사용할 수 있도록 UX 구조를 재설계했습니다.

 

주유, 세차, 정비 등 다양한 기능을 하나의 흐름으로 연결하고, 사용자가 필요한 기능에 빠르게 도달할 수 있도록 탐색 구조와 인터페이스를 정리했습니다.

Date
2020.12
Client
SK에너지
Output
Mobile App
Role
UX Design, Service Design

Project Goal

오프라인 중심의 차량 관리 경험을 직관적이고 효율적인 모바일 서비스로 전환하고, 사용자가 예측 가능하고 편리하게 이용할 수 있는 일관된 UX 구조를 설계하는 것을 목표로 했습니다.

Solution 01 (Service Structure)

주유 경험을 '등록 - 발견 - 선택 - 실행 - 보상'의 5단계 사용자 흐름으로 구조화했습니다.
복잡한 O2O 서비스를 사용자가 자연스럽게 이해하고 사용할 수 있도록 서비스 구조를 명확하게 설계했습니다.

Solution 02 (UI System)

주유, 세차, 정비 등 다양한 기능을 명확하게 구분할 수 있도록 카드형 UI 구조를 적용했습니다.
일관된 아이콘과 일러스트 스타일을 통해 서비스의 인지성과 사용 편의성을 높였습니다.

The Result

모바일 앱을 통한 간편 예약 이용이 약 35% 증가했으며, 주요 기능 사용률이 크게 향상되었습니다.
복잡한 오프라인 서비스를 효율적인 모바일 경험으로 전환하는 기반을 구축했습니다.

My Strength

O2O 서비스 특성을 고려한 사용자 흐름 설계와 정보 구조 정리를 통해 복잡한 기능을 단순화했습니다.
GUI 시스템과 인터랙션을 함께 설계하여 사용자가 직관적으로 이해할 수 있는 경험을 구현했습니다.
